# Bundled library

Put files in here to ship them **with the app**, for example a starter pack of animals:

- `animations/`: `.gif`, `.webp`, `.apng`, `.png`, `.webm`, `.mp4`, or Lottie `.json`
- `sounds/`: `.mp3`, `.wav`, `.ogg`, `.m4a`

The file name (without extension) is the name shown in Settings, so `Sleepy Panda.webp` appears as **Sleepy Panda**.

Users can also add their own files. They go into a personal library folder
(`%APPDATA%\BlinkBuddy\library`), which you can open from the tray menu.

Only ship files whose license allows it (CC0, or a license you've checked allows redistribution in apps).
Record where each one came from in `CREDITS.md`.
